# tweibley/homebrew-tap

Homebrew tap for [Hypermnesia](https://github.com/tweibley/hypermnesia) — local-first,
durable, decaying memory for your coding agents.

```bash
brew tap tweibley/tap
brew install --cask hypermnesia
```

The cask lands here with the first tagged release (v0.1.0); it is updated automatically by
Hypermnesia's release workflow on every tag.
